# Week 3：RAG

## 本阶段目标
解决「模型不知道公司内部知识」的问题：用 RAG 让 Agent 基于企业知识库回答，并给出引用来源。

## 必须掌握的知识
- Embedding、Vector、相似度
- Chunking（分块策略）
- Metadata（元数据过滤）
- Vector Search 与 Hybrid Search
- Reranking（重排）
- Context Window 与检索量的取舍
- Citation（引用来源）
- RAG Evaluation

## 技术栈建议
第一套不要搞复杂：Java + 一个向量数据库（如 pgvector 或 Qdrant）+ Spring 体系。

## Day 任务
| Day | 任务 |
| --- | --- |
| Day 1 ✅ | 学 Embedding 与向量检索原理，选型向量数据库（InMemory + all-minilm；笔记 `02-知识库/RAG/Day1-Embedding与向量检索原理.md`） |
| Day 2 | 跑通文档入库：分块 → Embedding → 写入向量库 |
| Day 3 | 实现检索接口：相似度检索 + 元数据过滤 |
| Day 4 | 实现 RAG 问答链路：检索 → 拼 Prompt → 生成 + 引用 |
| Day 5 | 加入 Reranking 与 Hybrid Search |
| Day 6 | 建立 RAG 评估用例（召回是否准确、引用是否正确） |
| Day 7 | 周总结 + 知识库更新 |

## 面试 / 工程问题

- Chunking 分太大 / 太小分别有什么问题？
