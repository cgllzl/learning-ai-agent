# Week 3 周总结：RAG —— 让模型会查企业知识

- 日期范围：2026-08-18 ~ 2026-08-23
- 已完成：
  - Day 1：Embedding 与向量检索原理 + 选型（InMemory + all-minilm，生产 Qdrant/pgvector）
  - Day 2：文档入库（分块 → Embedding → 向量库，真实本地模型跑通）

- 遇到的问题 / 踩坑：
  - 本地 Embedding 模块只有 1.18.1-beta28 预发布版；DeepSeek 不提供 Embedding API
  - `Metadata.put` 只有类型化重载，Map<String,Object> 要转 String
  - 私有嵌套类在 lambda 泛型推断里退化，方法引用要配 getter
  - 评估里"宽松引用"（有一处对就过）会漏判幻觉引用，改为严格模式
- 新学到的技术点：
  - Embedding / 余弦相似度 / ANN 近似最近邻
  - DocumentSplitters 分块（size/overlap）
  - EmbeddingSearchRequest + MetadataFilterBuilder 元数据过滤
  - Hybrid Search：字符 bigram 关键词打分 + RRF 倒数排名融合（1/(k+rank), k=60）
  - RAG 评估三指标：recall@K、citationAccuracy（严格）、citationPrecision
  - Multipart 文件上传入库
