# Week 4：Agent Orchestration + MCP

## 本阶段目标
从「会做 AI 应用」进入「会设计 Agent 系统」：学会编排多个 Agent / 工具，并用 MCP 标准化外部工具接入。

## 必须掌握的知识
- Agent Orchestration：Supervisor、Sequential、Parallel、Conditional、Handoff、Agent State
- 多 Agent 协作模式与适用场景
- MCP 是什么、为什么存在、什么时候该用 / 不该用
- MCP 核心概念：Client、Server、Tools、Resources、Prompts、JSON-RPC
- MCP 生命周期与授权
