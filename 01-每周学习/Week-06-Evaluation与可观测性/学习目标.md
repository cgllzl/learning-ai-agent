# Week 6：Evaluation + Observability

## 本阶段目标
传统程序输出是固定字符串，Agent 输出不确定，必须建立评估与可观测体系。

## 必须掌握的知识
- Evaluation：正确性、召回、安全性、权限、长流程执行
- 评估用例与评估集
- 人工评估 + 自动化评估
- Observability：Trace（链路追踪）、Token 用量、成本、延迟
- 常见可观测工具与标准（如 OpenTelemetry）

## Day 任务
| Day | 任务 |
| --- | --- |
| Day 1 ✅ | 为项目核心场景建立评估用例清单（`com.enterprise.agent.evaluation.AgentEvalCaseCatalog`；笔记 `02-知识库/Evaluation/Day1-评估用例清单.md`） |
| Day 2 | 实现自动化评估脚本（正确性 / 引用准确性） |
| Day 3 | 接入 Trace：一次对话全链路可追踪 |
| Day 4 | 记录 Token 用量、成本、延迟指标 |
| Day 5 | 把评估结果接入 CI，回归自动跑 |
| Day 6 | 针对失败用例复盘改进 |
| Day 7 | 周总结 + 知识库更新 |

## 面试 / 工程问题
- Agent 输出不确定，如何做回归测试？
- Evaluation 和单元测试的关系是什么？
- 一次 Agent 调用如何追踪完整链路？
