## 三、现在已经能回答的企业问题

- 为什么不是所有场景都用 Multi-Agent？先用最简单架构，再用质量、成本、延迟和稳定性数据比较。
- 为什么有幂等还需要补偿？幂等防重复执行，补偿处理已经发生但后续失败的业务影响。
- 为什么 Prompt 里说“必须安全”还不够？权限、审批、租户与审计必须在模型外的确定性代码中执行。
- 为什么 MCP Server 能连上仍不能直接信任？还要审核来源、绑定部署实例、校验 Tool Schema、限制 Scope 并检查运行时输出。
- 为什么 Skill 不是 Tool？Skill 是 SOP，Tool 才是具有真实副作用的执行接口；Skill 无权绕过 Tool 门禁。
- 为什么评估不能只看一条漂亮回答？要看业务结果、调用轨迹、重复运行波动、P95 和成本。
