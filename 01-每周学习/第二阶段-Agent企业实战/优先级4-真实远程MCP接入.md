# 优先级 4：真实远程第三方 MCP 接入

> 状态：待开始。建议 3 个学习日；依赖优先级 1～3 的安全、追踪与测试环境。对应 Sprint 5/7。

## 为什么最后做

Day 5 已用本地等价 Server 验证 Tool 审核、Schema 指纹和输出门禁。真实远程接入还多了外部服务、OAuth、网络与凭证链路。先有稳定的本地系统和 Trace，才能看清错误究竟发生在认证、协议、工具还是业务层。

## 三个学习日

| 日 | 学习任务与企业例子 | 离线验证 | 真实模型验证 |
| --- | --- | --- | --- |
| 1 | 选定可信第三方只读 MCP，记录版本、工具目录、Schema、网络出口和数据范围；完成 OAuth/PKCE 流程设计 | 错误 audience、过宽 Scope、目录变化必须阻断 | DeepSeek 只读查询可见 Tool 清单 |
| 2 | 真正拿授权 Token 联调资源服务器；验证 issuer/audience/scope/expiry 与凭证隔离 | 过期、错 audience、跨租户 Token 全拒绝 | DeepSeek 调用审核后的只读 Tool |
| 3 | 验证代理/网关/下游不透传 Token，脱敏日志与审计；做故障注入和回滚 | Token 不落日志、未审核 Tool 不可见、失败关闭 | 真实远程只读任务端到端完成 |

## 完成标准

- [ ] 真实第三方 Server 与 OAuth 授权服务器端到端可用。
- [ ] Token Claim 和最小 Scope 在实际请求中被验证；凭证不透传、不入日志。
- [ ] 新增或变化的 Tool 在审核前不会进入模型工具面。
- [ ] 真实 DeepSeek + 远程 MCP 完成一项只读任务，留下可审计 Trace。

若第三方服务或测试凭证尚未具备，只保留现有本地等价验证，明确写出外部依赖，不把模拟结果标成远程联调成功。
