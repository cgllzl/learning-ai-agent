# Week 5 周总结：企业级 Agent 安全

- 已完成：

  - Day 2：给 Agent 接入 RBAC 与租户隔离

  - Day 6：审计日志 + 高危操作人工审批流
- 遇到的问题 / 踩坑：
  - 审批语义一开始写成「无待审批单即视为已批准」，导致高危操作第一次就直接执行；改为「只有显式 approve 后才视为已批准」
  - `ToolProviderRequest.builder().build()` 会校验 invocationContext/userMessage 非空，测试时要用带参构造器
- 新学到的技术点：
  - RBAC：`SecuritySubject` + `RbacService`，按角色判断权限
  - 租户隔离：`TenantContext` 用 ThreadLocal 绑定当前租户
  - Tool 权限：`PermissionAwareToolProvider` 动态过滤工具
  - Prompt Injection：规则检测 + 系统提示词加固
  - Secret 管理：`SecretValue` toString 永远脱敏
  - 审计与审批：`AuditLogService` + `HumanApprovalService`
