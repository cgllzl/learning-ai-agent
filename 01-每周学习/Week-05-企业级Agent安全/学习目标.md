# Week 5：企业级 Agent 安全

## 本阶段目标
让 Agent 从「能工作」变成「能进企业生产环境」，重点是权限与安全。

## 必须掌握的知识
- RBAC、Tenant Isolation（租户隔离）
- Tool Permission（最小权限原则）
- Prompt Injection 与防护
- Sensitive Data 保护、Secret Management
- Audit Log（审计日志）
- Human Approval（关键操作人工审批）

## Day 任务
| Day | 任务 |
| --- | --- |
| Day 1 ✅ | 梳理项目里所有 Tool 的权限矩阵（`com.enterprise.agent.security.ToolPermissionCatalog`；笔记 `02-知识库/Agent安全/Day1-权限矩阵梳理.md`） |

| Day 7 | 周总结 + 知识库更新 |

## 面试 / 工程问题
- 为什么 Agent 不应该拥有所有 Tool 的权限？
- Prompt Injection 攻击面有哪些？如何缓解？
- 敏感数据如何防止被 Agent 带进上下文？
- 高危操作（改订单状态、转账）如何加人工审批？

## 完成标准
- [ ] Tool 调用带权限校验，越权调用被拒绝
- [ ] 密钥集中管理，日志中无明文密钥
- [ ] 高危操作有审批流程
- [ ] 关键操作有审计日志
