- 遇到的问题 / 踩坑：
  - AiServices 需要引入 `langchain4j` 主模块（只在 langchain4j-core 里找不到）
  - `@Tool` 与模型方法同名 `chat` 容易混淆（一个是接口方法，一个是 LangChain4j 客户端方法）
  - 工具参数由模型生成，必须做校验（Day 5 用改状态工具体现）
- 新学到的技术点：
  - Agent Loop：模型决策 → 执行工具 → 结果回填 → 继续，由 AiServices 代理自动完成
  - `@Tool` / `@P` 注解自动生成 ToolSpecification（name/description/parameters）
  - `AiServices.maxSequentialToolsInvocations` 防死循环
  - record + `@ConfigurationProperties` + compact constructor 的配置类写法
  - AiServices 工具异常默认兜底：异常回填给模型，Agent 不崩溃
