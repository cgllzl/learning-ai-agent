# Week 2：Tool Calling —— 真正进入 Agent

## 本阶段目标
理解「LLM 不只是回答问题，还能调用你的 Java 代码」，用 LangChain4j 完成第一个 Tool Calling Agent。

## 必须掌握的知识
- Function Calling / Tool 定义（name、description、parameters、JSON Schema）
- Agent Loop：LLM 决定调哪个工具 → 执行工具 → 结果回填 → 继续
- LangChain4j 的 @Tool 注解与 AiServices
- Tool 参数校验与错误处理
- 何时该用 Tool、何时不该用

## Day 任务
| Day | 任务 |
| --- | --- |
| Day 1 | 了解 Function Calling 原理，读 LangChain4j Tools 文档 |
| Day 2 | 写第一个 Java Tool（如查询订单）并注册给 LLM |
| Day 3 | 实现「企业订单 Agent」：查询订单 |
| Day 4 | 扩展：查询用户 / 物流 / 商品 |
| Day 5 | 扩展：修改订单状态（带参数校验与权限） |
| Day 6 | 处理 Tool 报错、超时、Tool 选择错误的兜底 |
| Day 7 | 周总结 + 知识库更新 |

## 面试 / 工程问题
- Tool 描述写得不好会怎样？（影响模型选择）
- Agent 陷入循环怎么办？如何限制最大迭代次数？
- Tool 的入参由模型生成，如何保证安全性？
- 为什么 Tool 权限要最小化？

## 完成标准
- [ ] 至少 4 个 Tool 可用，模型能按意图自动调用
- [ ] 修改订单状态有权限校验
- [ ] Agent 有最大迭代次数限制
