## 这是什么

把「学习 AI Agent」从「刷课」改成「边学习、边造一个真正能写进简历的企业级 Agent」。
学习路线、知识库、资料源、项目、日志五块相互关联，任何一步学习都会同步沉淀到这里。

## 核心原则

1. **不先学 Python / 机器学习 / Transformer**：直接围绕“能落地的 Agent 系统”学，在项目中反向补知识。
2. **Java 背景是优势**：Spring Boot → Agent 后端，REST → Tool API，MySQL/Redis → 持久化与 Memory，Docker/CI/CD → 部署与 Production。
3. **资料来源分优先级**：官方文档 > 官方 GitHub > 论文 > 高质量文章 > 社区。
4. **每个功能都能在知识库找到对应文档**：知识库 ↔ 项目功能一一映射，不“学过就忘”。
