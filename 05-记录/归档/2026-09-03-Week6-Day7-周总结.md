## 关键结论

- 评估用例要把自然语言检查点改成机器可判定的关键词。
- Agent 调工具会产生多轮模型请求，Token 必须累计，否则成本被低估。
- CI 分两层：离线门禁不花钱，真实联调需要 Key。
- Trace + 指标 + 日志三者结合，才能完整还原一次 Agent 调用。

## 踩坑记录

- 检查点写成“包含 O1001”无法直接做机器判断，改为 O1001 关键词。
- 单次 tokenUsage 会低估工具调用型 Agent 的成本，需用 listener 累计。
