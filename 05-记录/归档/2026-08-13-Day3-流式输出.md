## 接口示例

```http
POST /chat/stream
Content-Type: application/json

{ "messages": [ { "role": "user", "content": "用三句话介绍 Java 21" } ] }
```

```text
data:Java 21
data: 带来了……
data:[DONE]
```

## 关键点

- SSE = 基于 HTTP 的服务器单向推送（`text/event-stream`），适合 LLM 打字机效果；WebSocket 是双向的，这里用不到。
- LangChain4j 1.18 流式三回调：`onPartialResponse`（增量）/ `onCompleteResponse`（结束）/ `onError`（出错）。
- **踩坑**：SSE 默认按 ISO-8859-1 编码，中文必乱码；必须显式设置 UTF-8（见 `05-记录/踩坑记录.md`）。
