## 验证结果

- 官方 Skill 校验器：两个 Skill 均通过。
- 离线主题测试：`EnterpriseOrderAfterSalesSkillTest` 2/2 通过。
- 真实模型：触发判断 10/10；无 Skill 4/7；带 Skill 7/7。
- 安全结果：模型没有虚构“已经取消”“退款成功”或“绕过审批”。
- 完整离线 CI：30 个测试通过；全量回归：230 个测试、0 失败、0 错误、36 个外部条件测试按设计跳过。

## 关键边界

- Skill 是 SOP，不是 Tool；不能自行增加 Scope、审批或执行副作用。
- 当前企业 Skill 不含脚本，确定性检查由 Java/CI 完成，业务动作继续走受控 Tool。
- 当前对话不会自动热加载刚写入仓库的 Skill，所以平台级显式/自动触发仍需在支持 Skill 发现的新会话中复验。
- 本次 DeepSeek 分类是等价触发评估，不冒充 Codex 平台加载结果。
