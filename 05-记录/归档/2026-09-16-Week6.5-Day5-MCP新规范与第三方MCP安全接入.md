## 当前边界

- 项目尚未端到端支持 MCP `2026-07-28` 的 `server/discover`、MRTR、Tasks、现代缓存提示和订阅。
- 尚未连接真实远程第三方 MCP，也未实现 OAuth 发现、Authorization Code + PKCE 与 step-up 的完整流程。
- Tool 指纹是企业策略补强，只能证明清单未变化，不能证明第三方运行时代码永不作恶。
- `McpToolProvider.filter` 保护模型工具面；任何裸 `McpClient.executeTool` 入口仍需经过统一执行策略。
- Tool 名级可见性许可不是参数级执行审批；生产写操作还要绑定参数、租户、审批单、有效期和次数。
- 远程 Transport 只完成离线配置检查，没有覆盖代理、网关、Token Claim 和下游不透传。
