# 8 周学习路线（第一阶段）

> 目标：不无限扩展，8 周内形成一套完整的 Agent 工程能力，并完成企业级项目第一轮迭代。

## 不建议一开始做的事

- 花几个月学 Python、机器学习数学、Transformer 源码、自己训练模型
- 同时学 LangChain、LangGraph、CrewAI、AutoGen 等一堆框架
- 看几十门课程但一个项目都不写

## 每周安排

| 周 | 主题 | 交付物 | 对应知识库 |
| --- | --- | --- | --- |
| Week 1 | LLM 应用开发基础 | `/chat` API：JSON 输入输出 + Streaming + Structured Output + Retry + Error Handling | `02-知识库/LLM应用开发`、`Prompt工程` |
| Week 2 | Tool Calling | 企业订单 Agent：查订单/用户/物流/商品、改订单状态 | `02-知识库/Tool-Calling` |
| Week 3 | RAG | 企业内部知识问答，带引用来源 | `02-知识库/RAG` |
| Week 4 | Agent Orchestration + MCP | 用 LangChain4j + MCP 做工具标准化接入 | `02-知识库/Agent编排`、`MCP` |
| Week 5 | 企业级 Agent 安全 | RBAC、租户隔离、Tool 权限、Prompt Injection 防护 | `02-知识库/Agent安全` |
| Week 6 | Evaluation + Observability | 评估用例、可观测性接入 | `02-知识库/Evaluation`、`可观测性` |
| Week 7~8 | 企业级项目 | Enterprise AI Knowledge & Operations Agent | `04-项目/Sprints` |

## Java 能力到 Agent 能力的映射

| 你现在的 Java 能力 | 转到 Agent 后 |
| --- | --- |
| Spring Boot | Agent 后端服务 |
| REST API | Agent API / Tool API |
| MySQL / PostgreSQL | Agent 数据持久化 |
| Redis | Memory / Cache |
| MQ | Agent 异步任务 |
| 微服务 | Agent Service / Tool Service |
| Docker | Agent 部署 |
| JWT / RBAC | Agent 权限控制 |
| 日志 | Agent Trace |
| 单元测试 | Agent Evaluation |
| CI/CD | Agent Production |
| 分布式系统 | Multi-Agent / Workflow |

## 真正要补的能力

LLM + Agent 思维 + RAG + Tool + MCP + Evaluation + AI Security
（不是“编程”）
