# 导师式学习方式（每阶段固定格式）

以后每个阶段都按这个格式推进，保证「学得少但学得深」。

1. **本阶段目标** —— 解释为什么学
2. **必须掌握的知识** —— 只给真正需要的，不无限扩展
3. **官方资料** —— 每个资料标明：名称 / 类型（官方文档、论文、参考实现）/ 链接
4. **实践任务** —— 直接写代码
5. **面试 / 工程问题** —— 例如：
   - 为什么 Agent 不应该拥有所有 Tool 的权限？
   - RAG 为什么会召回错误内容？
   - 为什么 Agent 有时候会陷入循环？
   - Multi-Agent 一定比 Single-Agent 好吗？
6. **企业项目** —— 把刚学的技术加入项目
7. **知识库更新** —— 把资料、笔记、代码、项目全部关联起来

## 资料来源优先级（Level 1～5）

| 级别 | 类型 | 用途 |
| --- | --- | --- |
| Level 1 | 官方文档 | 事实来源，例如 LangChain4j / Spring AI / MCP / OpenAI Platform Docs |
| Level 2 | 官方 GitHub / Reference Implementation | 真正写代码时参考 |
| Level 3 | 原始论文 | 理解 Agent、RAG、Evaluation 原理 |
| Level 4 | 高质量技术文章 | 补充工程实践 |
| Level 5 | Reddit / 社区 | 只用来发现实际开发遇到的问题，不作为唯一事实来源 |
