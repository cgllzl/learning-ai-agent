# 知识库（02-知识库）

> 这是你的「第二大脑」：学习过程中所有概念、资料、笔记都按主题沉淀在这里。

## 主题目录

| 主题 | 目录 | 对应学习周 |

## 每条笔记必须包含

- 日期
- 来源链接（按 Level 1～5 标注级别）
- 核心内容（用自己的话）
- 关联项目功能 / Sprint
- 关联资料源（`03-资料源/`）

## 使用方式

- 每次学完一个知识点 → 在对应主题下新建一篇笔记（可复制 `笔记模板.md`）。
- 每次项目新增功能 → 在 `05-记录/知识库-项目映射.md` 登记「功能 ↔ 知识库文档」。
