# Memory（记忆）

## 核心概念
- 短期记忆（对话上下文）vs 长期记忆（外部存储）
- Context Management（上下文管理：截断、摘要、滑动窗口）
- Memory Architecture（记忆架构）
- 用 Redis / 数据库做记忆持久化
- 记忆与 RAG 的关系
