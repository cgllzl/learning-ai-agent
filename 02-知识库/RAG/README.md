# RAG（检索增强生成）

## 核心概念
- Embedding 与向量
- Chunking（分块策略）
- Metadata（元数据过滤）
- Vector Search 与 Hybrid Search
- Reranking（重排）
- Context Window 与检索量取舍
- Citation（引用来源）
- RAG Evaluation（评估）
