# Sprint 10：Production

## 目标
把项目部署成可上线的生产系统。

## 任务
- [ ] 完善 Docker 化与配置管理
- [ ] CI/CD 流水线：构建 → 测试（含评估）→ 部署
- [ ] dev / staging / prod 环境划分
- [ ] 灰度发布与回滚方案
- [ ] 成本控制（模型用量、缓存、限流）
- [ ] 项目 README：架构图 + 技术栈 + 亮点
- [ ] 前端静态资源或独立 Web 容器纳入构建、健康检查和发布流程
- [ ] smoke/demo/load 数据生成、迁移和回滚命令可复现
- [ ] 压测报告、页面截图、演示脚本/视频和简历描述完成

## 技术
Docker / CI-CD / 环境管理 / 限流

## 知识库映射
- `02-知识库/部署与工程化/`

## 完成标准
- [ ] 一键部署到测试环境
- [ ] 项目文档完整，可对外展示
- [ ] 新机器从空环境启动后可生成 demo 数据并完成三条核心演示链
- [ ] 简历中的数据规模和性能数字能追溯到测试报告
